# Music Reorder

Many car stereos don't have a shuffle mode, so songs by the same artist often play back to back. Music Reorder fixes that. It makes a copy of your music folder with the songs in a new, mixed order.

Each file gets a number at the start of its name (`001 - Song.mp3`, `002 - Song.mp3`, and so on). Most car stereos play files in name order, so the numbers keep the new order.

## Download

Go to the [Releases](../../releases) page and download `MusicReorder.exe` from the latest version. You don't need to install anything, and Python isn't required.

This app is for Windows only.

## How to use

1. Open `MusicReorder.exe`.
2. Choose your music folder, or drag it into the window.
3. Click the button to start.
4. Copy the new folder to your USB drive or SD card.

## Good to know

- Your original files are never changed.
- The new folder is created next to the original, with `_Shuffled` added to its name. For example, `Music` becomes `Music_Shuffled`.
- Each time you run the app, you get a new order and the previous shuffled folder is replaced.
- If one artist has far more songs than the others, some of their songs may still end up next to each other.
- Songs without an artist tag are grouped as "Unknown Artist".
- Supported formats: MP3, FLAC, M4A, AAC, OGG, WAV, and WMA.

The first time you run the app, Windows may show a warning because the file isn't signed. Click **More info**, then **Run anyway**.

# تغییر ترتیب آهنگ‌ها

خیلی از استریوهای ماشین حالت shuffle ندارند، پس آهنگ‌های یک خواننده اغلب پشت سر هم پخش می‌شوند. این برنامه همین مشکل را حل می‌کند. از پوشه‌ی موسیقی شما یک کپی با ترتیب جدید و درهم می‌سازد.

جلوی اسم هر فایل یک شماره اضافه می‌شود (`001 - Song.mp3`، `002 - Song.mp3` و همین‌طور تا آخر). بیشتر استریوهای ماشین فایل‌ها را بر اساس نام پخش می‌کنند، پس همین شماره‌ها ترتیب جدید را نگه می‌دارند.

## دانلود

از صفحه‌ی [Releases](../../releases) آخرین نسخه را دانلود کنید و فایل `MusicReorder.exe` را بگیرید. نیازی به نصب یا پایتون نیست.

این برنامه فقط برای ویندوز است.

## روش استفاده

۱. فایل `MusicReorder.exe` را اجرا کنید.
۲. پوشه‌ی موسیقی را انتخاب کنید یا آن را داخل پنجره بکشید و رها کنید.
۳. روی دکمه‌ی شروع کلیک کنید.
۴. پوشه‌ی جدید را روی فلش یا کارت حافظه‌ی ماشین کپی کنید.

## نکات

- فایل‌های اصلی هیچ‌وقت تغییر نمی‌کنند.
- پوشه‌ی جدید کنار پوشه‌ی اصلی ساخته می‌شود و به اسمش `_Shuffled` اضافه می‌شود. مثلاً `Music` می‌شود `Music_Shuffled`.
- هر بار که برنامه را اجرا کنید، ترتیب جدیدی ساخته می‌شود و پوشه‌ی قبلی جایگزین می‌شود.
- اگر یک خواننده خیلی بیشتر از بقیه آهنگ داشته باشد، ممکن است بعضی از آهنگ‌هایش هنوز کنار هم بیایند.
- آهنگ‌هایی که تگ خواننده ندارند، زیر عنوان «خواننده نامشخص» گروه‌بندی می‌شوند.
- فرمت‌های پشتیبانی‌شده: MP3، FLAC، M4A، AAC، OGG، WAV و WMA.

ممکن است دفعه‌ی اول ویندوز هشداری نشان دهد چون فایل امضای دیجیتال ندارد. روی **More info** و سپس **Run anyway** کلیک کنید.
